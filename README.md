# TTZip App Core

TTZip Universal Cross-Platform Headless Application Core.

This repository is the standalone, publicly licensed projection of the TTZip
application core. It is self-contained: the Rust crate, the vendored
`ttzip-types` crate, the Swift package, and the artifact generation scripts all
live here, and no monorepo checkout is required.

## Layout

- `src/` — `ttzip-app-core` Rust crate (MTP, ADB, transfer, workspace, UniFFI surface)
- `crates/ttzip-types/` — vendored shared data-type crate
- `Sources/TTZipAppCore/` — Swift target, including generated UniFFI bindings
- `Sources/CTTZipAppCoreBridge/` — C bridge target and public headers
- `Tests/TTZipAppCoreTests/` — Swift package tests
- `scripts/` — artifact generation scripts

## Build

Build the Rust static library and package the XCFramework:

```sh
./scripts/build_rust.sh --debug
```

The script writes `Frameworks/TTZipAppCoreVendor.xcframework` and
`Frameworks/libttzip_desktop.a`. Both are build artifacts and are not tracked.

## Test

```sh
cargo test --workspace
swift test
```

`swift test` requires the XCFramework from `scripts/build_rust.sh` to exist first.

## UniFFI bindings

`Sources/TTZipAppCore/Generated/ttzip_app_core.swift` and
`Sources/CTTZipAppCoreBridge/include/ttzip_app_coreFFI.h` are generated by `uniffi-bindgen`
and checked in so the package builds without the generator. Regenerate them with:

```sh
cargo install uniffi-bindgen --version 0.28.3
./scripts/generate_uniffi.sh --debug
```
